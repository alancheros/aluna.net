# Aluna.net

Aluna.net is a .NET event sourcing toolkit that provides:

- Domain abstractions for commands, events, and aggregates
- Repository implementations
- Event store contracts and implementations (in-memory and SQL Server)
- Logging decorators for repositories and event stores

## Installation

```bash
dotnet add package Aluna.net
```

## Usage

Reference the package from your application and compose the provided abstractions and event store/repository components for your domain model.

## Aluna

Aluna is the place where reality exists before it becomes visible.

Every river, mountain, tree, and person is first conceived in Aluna, not as a finished object, but as a complete history of intentions, decisions, and meanings. The world we can touch is merely the latest expression of that deeper record.

To understand something, the Kogi do not look only at its current form. They seek the sequence of thoughts, relationships, and acts that brought it into being. In this view, reality is not defined by its present state, but by the accumulated story that produced it.

Aluna is therefore the invisible memory of the universe: a living archive where nothing truly disappears, where every creation leaves a trace, and where the meaning of the present can always be reconstructed from what came before.
